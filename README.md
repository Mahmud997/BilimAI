MAX-версия школьной образовательной AI-платформы, подготовленная для GitHub Pages.

## Что проверено и улучшено

- Исправлена логика навигации и локального режима.
- Исправлен таймер ЕНТ: при достижении нуля тест корректно завершается.
- Импорт вопросов Excel теперь реально заменяет/обновляет банк вопросов, а не только сохраняет сырой JSON.
- Импортированный банк используется в ЕНТ и вступительном тестировании.
- Добавлена история результатов с процентами.
- Добавлена аналитика и график последних попыток.
- Добавлена резервная копия/восстановление JSON.
- Добавлен поиск по банку вопросов.
- Добавлена тёмная тема.
- Добавлен безопасный HTML-экранированный вывод пользовательских/Excel данных.
- AI оставлен совместимым с Gemini, OpenAI и DeepSeek.
- Firebase работает в двух режимах: локальный demo без Firebase и Google/Firebase при заполненной конфигурации.
- Добавлена запись результатов в Firestore для авторизованного пользователя.
- Сохранены основные разделы исходной версии: ЕНТ, приём, олимпиады, профессии/гранты, администрирование, Excel, AI.

## Важно

GitHub Pages — статический хостинг. API-ключ AI, если введён в браузере, хранится локально в localStorage и может быть доступен пользователю браузера. Для production не храните секретные ключи во фронтенде. Используйте Firebase Cloud Functions или другой backend proxy.

## Запуск

1. Загрузите содержимое проекта в GitHub repository.
2. Settings → Pages → Deploy from branch.
3. Выберите `main` и `/root`.
4. Откройте опубликованный адрес.

Для Firebase смотрите `firebase-setup.md` и `firestore.rules`.

## Формат Excel для вопросов

| id | subject | type | question | optionA | optionB | optionC | optionD | correct |
|---|---|---|---|---|---|---|---|---|
| Q001 | Математика | quiz | 2+2=? | 3 | 4 | 5 | 6 | 1 |

`correct` — индекс правильного варианта: 0=A, 1=B, 2=C, 3=D.

## Формат Excel для учеников

`studentId, fullName, grade, subjects, phone, parentName`

## Архитектура

Сейчас проект намеренно оставлен в одном `index.html`, чтобы он запускался на GitHub Pages без сборщика и npm.

Для следующего production-шага можно разделить его на:
- `index.html`
- `css/app.css`
- `js/core.js`
- `js/firebase.js`
- `js/ai.js`
- `js/tests.js`
- `js/admin.js`
- `js/analytics.js`
